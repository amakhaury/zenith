# ZENITH — лендинг изделий из натурального камня

Статический сайт: только HTML, CSS и JS. Сервер, PHP и база данных не нужны.
Публикуется через GitHub Pages из папки `docs/`.

## Структура
- `site.config.json` — бренд, телефон, WhatsApp, адрес сайта, реквизиты, ID Яндекс Метрики.
- `src/` — исходники: `index.html`, `politika/`, `404.html`, `assets/` (CSS, JS, картинки, шрифты, логотип).
- `tools/build.py` — сборка `src/` → `docs/` (подстановка данных из конфига, CSP, sitemap, robots).
- `docs/` — готовый сайт. **Руками не править** — пересобирается командой ниже.

## Сборка
    python3 tools/build.py

После изменений в `src/` или `site.config.json` пересоберите и закоммитьте `docs/`.

## Адрес сайта и свой домен
`siteUrl` в `site.config.json`:
- `https://amakhaury.github.io/zenith` — адрес GitHub Pages, ссылки собираются с префиксом `/zenith`;
- `https://ваш-домен.ru` — свой домен: сборка создаст `docs/CNAME`, ссылки пойдут от корня.
  В DNS домена: четыре A-записи `@` → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
  и CNAME `www` → `amakhaury.github.io`. Затем в Settings → Pages → Custom domain включить Enforce HTTPS.

## Заявки — через WhatsApp
Форма «Заказать услугу» (имя, услуга, сообщение) ничего не отправляет на сервер: по кнопке открывается
WhatsApp с готовым текстом на номер `whatsappNumber`. Кнопки «WhatsApp» и «Позвонить» есть в блоке заявки,
на телефоне внизу экрана закреплена панель с ними же.

## Шрифты
- Текст — Inter. Заголовки — Cormorant Light (замена шрифта Felidae из макета).
- Чтобы вернуть Felidae: положите `src/assets/fonts/felidae.woff2` и пересоберите.

## Перед запуском заполнить
- реквизиты ИП и email в `site.config.json` (используются в политике конфиденциальности);
- `metrikaId` — если нужна Яндекс Метрика.
